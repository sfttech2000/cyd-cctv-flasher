CYD CCTV Server 1.0.1 — คู่มือ
จอดูกล้องวงจรปิด (IP camera) 4 ช่อง บนบอร์ด CYD (ESP32-2432S028R จอ 2.8")
by tee & claude

== เปิดครั้งแรก ==
1. ต่อ Wi-Fi: จอแสดงรายชื่อ Wi-Fi แตะเลือก แล้วพิมพ์รหัสด้วยคีย์บอร์ดบนจอ
   (ใช้ Wi-Fi 2.4 GHz วงเดียวกับกล้อง)
   หรือกด "Use phone setup": บอร์ดเปิด Wi-Fi ของตัวเอง สแกน QR บนจอด้วยมือถือ แล้วเลือก Wi-Fi บ้าน
2. ต่อแล้วจอโชว์ที่อยู่หน้าตั้งค่า เช่น http://192.168.1.62/ พร้อม QR
   (หรือ http://cctvserver-xxxx.local/) เปิดด้วยมือถือหรือคอมที่ใช้ Wi-Fi เดียวกัน
3. ครั้งแรกบอร์ดจะลองหากล้อง VStarcam ในวง Wi-Fi ให้เอง (ทดลอง อาจไม่เจอ)

== ใส่กล้อง ==
ในหน้าเว็บตั้งค่า กรอก:
- Name  ชื่อกล้อง
- IP    ที่อยู่กล้อง เช่น 192.168.1.90 (ดูในแอปกล้อง หรือหน้ารายชื่ออุปกรณ์ในเราเตอร์)
- Port  พอร์ต HTTP ของกล้อง (ส่วนใหญ่ 80)
- Path  ที่อยู่ภาพนิ่ง ตามยี่ห้อ:
    VStarcam / Foscam : /snapshot.cgi
    Hikvision         : /ISAPI/Streaming/channels/101/picture
    Dahua             : /cgi-bin/snapshot.cgi
    ทั่วไป / ONVIF     : /onvif-http/snapshot  หรือ  /jpg/image.jpg
- Pass  รหัสกล้อง (ผู้ใช้คือ admin เสมอ)
กด + Add camera · ลูกศร ↑ ↓ เลื่อนลำดับ · × ลบ · Auto-scan หากล้อง VStarcam อีกรอบ
บนจอก็ตั้งได้: กดปุ่ม SET

== หน้าจอ ==
- 4 ช่อง: ปุ่ม <PG / PG> เลื่อนหน้า (สูงสุด 16 กล้อง = 4 หน้า)
- แตะช่องไหนดูกล้องนั้นเต็มจอ: ปุ่มล่างซ้าย/ขวา เลื่อนกล้อง, BACK มุมซ้ายบนกลับ 4 ช่อง
- ปิดเปิดใหม่ จะกลับมาที่หน้าที่ดูล่าสุด
- NO SIG / NO SIGNAL = ดึงภาพไม่ได้: เช็ก IP, พอร์ต, Path และรหัส

== ข้อจำกัด ==
- ภาพราว 1-2 ภาพต่อวินาที (ดึงภาพนิ่ง ไม่ใช่วิดีโอ)
- กล้องที่มีแต่ RTSP / H.264 (กล้องคลาวด์รุ่นใหม่ที่ใช้แต่แอป) ใช้ไม่ได้
- VStarcam พอร์ตอาจเปลี่ยนเอง ถ้าภาพหาย แก้พอร์ตในหน้าตั้งค่า

== เปลี่ยน Wi-Fi ==
กด SET บนจอ แล้วเลือกตั้ง Wi-Fi ใหม่
หรือติดตั้งใหม่แบบ "ล้างเครื่องแล้วลงใหม่" ในหน้าติดตั้ง (กล้องที่ใส่ไว้จะหายด้วย)
